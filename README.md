# Production Incident Copilot

An AI-powered debugging assistant that helps engineers analyze production logs, retrieve relevant incidents, and generate root-cause summaries.

## Problem Statement
Production incidents often require engineers to manually inspect thousands of log lines. This project aims to reduce debugging time by combining log retrieval and LLM-based reasoning.

## Planned Features
- Upload and parse logs
- Search relevant log chunks
- Retrieve similar historical incidents
- Generate root-cause summaries
- Suggest possible next actions

## Tech Stack
- Python
- FastAPI
- ChromaDB
- OpenAI API
- Pytest
- GitHub Actions
